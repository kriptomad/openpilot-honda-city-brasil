# archive/

Historical material kept verbatim for traceability. Nothing here is maintained; the files
still use the paths and names of the development repository.

| Path | What it is |
|---|---|
| `baseline-original/` | Unmodified copy of the original KiCad project the Hybrid Panda PCB was derived from: lukasloetkolben/OpenBlackPanda (OpenpilotHardware BlackPanda v2, STM32F413, MIT 2023). It is the reference for every "baseline" comparison in the reports (DRC baseline, schematic parity, footprint audit). The derived project lives in [../hardware/hybrid-panda](../hardware/hybrid-panda). |
| `manifests/` | SHA-256 manifests of the development working tree taken at the end of each protocol step (`OUTPUT_ROOT_STEP*_<date>.sha256`), of the baseline before and after each step (`original_*.sha256`, `baseline_copy.sha256`) and of the read-only reference clones (`reference_clones.sha256`). They prove the baseline was never modified and record the state of the tree at each checkpoint. Generated by `hardware/scripts/Make-Manifest.ps1`. |
| `output-root.txt` | Marker file of the development tree stating its root path. |
